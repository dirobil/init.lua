# Отключённые плагины

Файлы в этой папке **не загружаются**, потому что `lazy.nvim` собирает спеки
только из `lua/dirobil/lazy/*.lua` (рекурсивный импорт `dirobil.lazy` не
включает подпапки как модули плагина).

## Как включить плагин по одному

1. Переместите файл из этой папки в `lua/dirobil/lazy/`:
   ```sh
   git mv lua/dirobil/lazy/disabled/gitsigns.lua lua/dirobil/lazy/gitsigns.lua
   ```
2. Перезапустите Neovim — Lazy сам установит новый плагин (`:Lazy` для контроля).
3. Если плагин тянет за собой зависимости, они подтянутся автоматически.

## Рекомендуемый порядок подключения (от простого к сложному)

| Шаг | Плагин        | Что даёт                                             |
|-----|---------------|------------------------------------------------------|
| 1   | comment       | `<leader>/` — комментировать строки/блоки            |
| 2   | gitsigns      | знаки git в gutter, `]c`/`[c` — прыжки по изменениям |
| 3   | which-key     | всплывающая подсказка клавиш (помогает запоминать)   |
| 4   | nvim-treesitter | улучшенная подсветка и indent                     |
| 5   | lualine       | статус-бар со всей информацией                       |
| 6   | conform       | форматирование файлов `<leader>f`                    |
| 7   | lsp           | автодополнение + LSP (самое объёмное, ставьте последним) |

## Примечания
- `lsp.lua` использует mason.nvim — на Windows требует установленный `git` и
  `node`, на Termux дополнительно `ripgrep` и `node` (см. README репозитория).
- Все конфиги уже содержат `pcall`-защиту и fallback'ы, поэтому включение/
  выключение любого файла безопасно.
